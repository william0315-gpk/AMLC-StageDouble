# 实施计划：前端图形界面 + UE 后端对接

## 概述
做两件事：
1. 把终端命令操作改成图形界面（滑块+按钮），同时集成 2D 小人预览
2. 写好 UE MetaHuman 对接代码，用户装了 UE 后直接导入使用

---

## 第一部分：前端图形界面 `app.py`

### 目标
一个窗口替代现在的 `ml_trainer_v2.py`（终端）+ `dashboard.py`（柱状图），用户不用敲命令，全用鼠标操作。

### 界面布局
```
┌─────────────────────────────────────────────────┐
│              StageDouble 控制台                   │
├──────────────────┬──────────────────────────────┤
│  录制参数设置      │  实时输出                      │
│                  │  ┌────────────────────────┐  │
│ 嘴巴开合 [====■==] │  │  柱状图 6 根            │  │
│ 表情强度 [==■====] │  │                        │  │
│ 头部角度 [===■===] │  └────────────────────────┘  │
│ 身体幅度 [=■=====] │                              │
│ 手臂高度 [====■==] │  2D 小人预览                  │
│ 动作速度 [==■====] │  ┌────────────────────────┐  │
│                  │  │   简笔画小人             │  │
│ 录制秒数 [  3  ]  │  │   嘴巴/头/手臂实时动     │  │
│                  │  └────────────────────────┘  │
│ [录制] [训练]      │                              │
│ [运行] [停止]      │  状态：●音频 ●动作           │
│ [清空]            │  样本数：12  已训练：是       │
└──────────────────┴──────────────────────────────┘
```

### 实现方式
- 用 tkinter（Python 自带，不需安装）
- 复用 `ml_trainer_v2.py` 中的核心类：`StreamReceiver`、`MergedFeatureReceiver`、`Trainer`、`build_model`
- 复用 `dashboard.py` 的柱状图逻辑
- 新增 2D 小人 Canvas 绘制：嘴用一个椭圆、头用圆、身体用线、手臂用线，根据 6 个参数实时变形

### 文件改动
- 新建 `app.py` -- 主程序入口，单文件完成全部 GUI
- `ml_trainer_v2.py` -- 不改，`app.py` 从中 import 核心类

---

## 第二部分：UE MetaHuman 对接

### 目标
写好 UE 端代码，用户装了 UE 后按文档操作即可让 MetaHuman 动起来。

### 文件清单
1. `ue/metahuman_osc.py` -- UE Python 脚本，在 UE 内运行，功能：
   - 启动 OSC Server 监听端口 12000
   - 接收 `/stagedouble/outputs` 的 6 个值
   - 将值映射到 MetaHuman 的 Control Rig 参数（下颌、表情、头部旋转、身体缩放、手臂旋转、动画速率）

2. `ue/setup_guide.md` -- 图文步骤说明，包括：
   - 如何安装 UE 和 MetaHuman
   - 如何启用 OSC 插件和 Python 插件
   - 如何导入并运行脚本
   - 6 个参数到 MetaHuman 骨骼的映射表

---

## 验证步骤
1. `python app.py` 能打开窗口，滑块和按钮可操作
2. 启动 `audio_extractor.py` 后，窗口状态栏显示"音频已连接"
3. 启动 `motion_extractor.py` 后，窗口状态栏显示"动作已连接"
4. 点"录制"能采集样本，样本数递增
5. 点"训练"后点"运行"，柱状图和 2D 小人实时变化
6. UE 脚文件存在，内容完整可读
